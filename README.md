# Genetic Algorithm Research Project
The goal of this project was to demonstrate the effectiveness of using a Genetic Algorithm to find solutions to a problem.  While in this example, we use pathfinding, the concept could easily be applied to other, possibly more interesting topics such as Inverse Kinematics.  All that would need to be done is implementation of a custom fitness function for whatever problem was meant to be solved.
